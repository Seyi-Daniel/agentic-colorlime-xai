# Committed benchmark evidence

These files are the compact evidence retained from the August 6 experiment:

- `results.csv`: 504 per-image rows across six methods and 84 images.
- `summary.csv`: original method-level summary.
- `prediction_summary.csv`: predictions for the 100 screened images.
- `run_config.json`: emitted settings with a repository-relative output path.
- `verified_metrics.json`: independently recalculated headline and paired counts.
- `headline_summary.csv`: two-row headline result summary.
- `paired_default_vs_colorlime.csv`: aligned default-LIME and Color-LIME results.

The derived files and README figures are regenerated by:

```bash
python scripts/analyze_benchmark.py --verify
```

No ImageNet images, model weights, NumPy caches, or per-image comparison sheets
are redistributed here.
